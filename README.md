# Shahnameh

Texts of Ferdowsi's _Shahnameh_: the Persian in several printed editions, a
Latin-script transliteration from the Tajik Cyrillic, four translations, and a
parallel-text reader. Each folder documents itself — start with its README.

| Folder                       | What's in it                                                                                                                                                                                                                            | Read                                                                                                                         |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `shahnameh-transliteration/` | Latin-script transliteration made from the Tajik Cyrillic edition — six volumes, 71,017 words, roughly the first half of the poem                                                                                                       | [README](shahnameh-transliteration/README.md) · [transliteration scheme](shahnameh-transliteration/transliteration-guide.md) |
| `multitext/`                 | Parallel-text reader for one 68-couplet passage (Pizzi's reading 1, Hushang): six editions, the transliteration and four translations, one couplet per row. Two HTML pages, no build step prepared with the assistance of Claude Opus 5 | [README](multitext/README.md)                                                                                                |
| `editions/`                  | Persian text of five editions — Ganjoor, Moscow and Tajiki in full; Macan and Vullers as local-only scans                                                                                                                               | [README](editions/README.md)                                                                                                 |
| `translations/`              | Warner (English), Mohl (French), Rückert (German), Atkinson and Zimmern abridgements — built on [Gregory Crane's TEI texts](https://github.com/gregorycrane/Shahnameh)                                                                  | [README](translations/README.md)                                                                                             |

Scans (PDFs) are kept locally and not tracked here — see [`.gitignore`](.gitignore).
The transcribed text of each is in the repository.
